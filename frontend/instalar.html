Instale o ValiStock

Abra direto da tela inicial, em tela cheia, como um app.

Baixar para Windows

Instalador .exe · Windows 10 e 11 (64 bits) · cerca de 110 MB

  1. Abra o arquivo ValiStock-Setup.exe que foi baixado.
  2. Se aparecer "O Windows protegeu o computador", clique em Mais informacoes e depois em Executar assim mesmo.
  3. Siga o instalador. No final, o ValiStock abre sozinho e ganha atalho na area de trabalho e no menu Iniciar.

    Se o botao de instalar nao apareceu:

    • Chrome no computador: clique no icone de instalar na barra de endereco, ou no menu ⋮ → Transmitir, salvar e compartilhar → Instalar pagina como app.
    • Edge: menu … → Aplicativos → Instalar este site como um aplicativo.
    • Android: no Chrome, menu ⋮ → Instalar app (ou Adicionar a tela inicial).
    • Outros navegadores: abra esta pagina no Chrome ou no Edge.

    Se voce ja instalou, abra o ValiStock pelo icone no computador ou na tela inicial do celular.

    Pronto, o ValiStock esta instalado!
